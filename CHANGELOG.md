# Changelog

## 0.1.0 — Limited pilot

- Category-based complement rules with deterministic specificity and priority matching.
- Bounded selection of eligible WooCommerce simple and variable products.
- Manual placement by shortcode or dynamic block, plus optional automatic product-page placement.
- Persian and English interface strings and localized recommendation heading.
- Opt-in deletion of Hamkharid rules and settings during uninstall.

This changelog describes the intended pilot build. The release report must record the exact build revision, QA results, and any remaining limitations.
